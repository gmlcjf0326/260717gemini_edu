# 20분 만에 이해하는 AI — 중1 제미나이 수업 콘텐츠 패키지

중학교 1학년 교실에서 **제미나이(Gemini) 웹의 게스트 모드(로그인 없이 사용)** 만으로 진행하는 **20분 × 4회차** 생성형 AI 리터러시 수업 패키지입니다. 지도안·학생 학습지·교사 키트(체크리스트, 트러블슈팅, 프롬프트(AI에게 건네는 질문·부탁의 말) 스니펫, 평가 루브릭 등)·확장 자료까지, 교사가 이 저장소 하나로 준비부터 평가까지 마칠 수 있도록 구성했습니다. 로그인이 없으므로 계정 발급·보호자 동의서 수합 없이 시작할 수 있고, 접속 실패·기기 부족에 대비한 플랜 B가 모든 차시에 들어 있습니다.

## 빠른 시작 — 수업이 내일이라면 이 순서로 읽으세요

1. **`teacher-kit/사전준비-체크리스트.md`** — 지금 당장 D-1 항목부터 실행합니다. 특히 학교 네트워크에서 시크릿 창으로 gemini.google.com **게스트 접속 3회 테스트**가 최우선입니다(실패 시 교사 시연으로 전환 준비).
2. **`curriculum/1차시-지도안-AI와-첫만남.md`** — 분 단위 흐름표와 발문 스크립트까지 정독합니다. 20분 수업이라 애드리브 여유가 없습니다.
3. **`teacher-kit/프롬프트-스니펫-모음.md`** — 1차시 실습 프롬프트를 교사 기기에서 직접 1회 실행해 결과를 확인합니다.
4. **`worksheets/1차시-학습지.md`** — 학급 인원수 + 여유분으로 인쇄합니다. 게스트 모드는 기록이 저장되지 않으므로 학습지가 곧 저장소입니다.

시간이 더 있다면 `curriculum/00-교육과정-개요.md`로 전체 설계와 운영 시나리오(1인 1기기/모둠 1기기/교사 시연)를 먼저 잡고, `teacher-kit/학부모-안내문.md`를 발송하는 것을 권장합니다.

## 4차시 아크 요약

| 차시 | 제목 | 핵심 질문 | 산출물 |
|---|---|---|---|
| 1 | AI와 첫 만남 — 인공지능은 어떻게 말할까? | AI는 어떻게 말을 만들까? | 첫 대화 기록 |
| 2 | 프롬프트의 기술 — AI에게 잘 부탁하는 법 | 어떻게 부탁해야 잘 나올까? | 나만의 레시피 카드 |
| 3 | AI 거짓말 탐정 — 환각 수사대 | AI의 말은 다 사실일까? | 수사 보고서 |
| 4 | AI와 함께 살아가기 — 정직한 사용 선언 | AI를 어디까지 써도 될까? | 나만의 AI 사용 선언문 |

아크는 "확률로 말을 만든다 → 잘 부탁하면 잘 나온다 → 그럴듯한 거짓도 만든다 → 어떻게 쓸지는 내가 정한다"의 순서로 쌓입니다. 각 차시는 도입(3분)–개념(3~4분)–실습(9~10분)–정리(3~4분), 합계 정확히 20분입니다.

## 주의 문구 (사용 전 반드시 확인)

- **기준일**: 이 패키지의 정책·기능·연령 관련 서술은 **2026년 7월 조사 시점 기준**입니다. AI 서비스는 예고 없이 바뀌므로 **실제 접속 화면이 최종 기준**입니다. 수업 전 게스트 접속 테스트를 생략하지 마십시오.
- **게스트 모드 전제**: 본편 4개 차시는 로그인 없이 진행합니다. 게스트 모드에서는 **이미지 생성·파일 업로드·대화 기록 저장이 불가능**하며, 학생에게 개인 구글 계정 로그인을 지시하지 않습니다(한국 자체 관리 연령 만 14세, 개인정보 보호법 제22조의2 관련 — 근거는 `appendix/제미나이-조사-정리.md`).
- **법률 자문 아님**: 이 패키지는 수업 설계 참고 자료입니다. 개인정보·계정 정책에 관한 최종 판단은 공식 문서, 학교 규정, 학교 개인정보 담당자·관리자와의 협의를 따르십시오.
- **AI 답변 예시**: 문서에 실린 AI 답변은 모두 "예시 답변(실제 결과는 매번 다름)"입니다. 같은 프롬프트라도 결과는 매번 달라지며, 수업은 어떤 결과가 나와도 성립하도록 설계되어 있습니다.
