# 20분 만에 이해하는 AI — 중1 제미나이 수업 콘텐츠 패키지 (3탄 시리즈)

중학교 1학년 교실에서 **제미나이(Gemini) 웹의 게스트 모드(로그인 없이 사용)** 만으로 진행하는 **20분 × 12회차(3탄 × 4차시)** 생성형 AI 수업 시리즈입니다. 시리즈의 궁극 목표는 **AI를 소비하는 학생이 아니라 AI로 직접 만들어 보는 학생**입니다.

- **1탄 「AI 리터러시 기초」** — 원리(확률) → 프롬프트 → 환각 검증 → 윤리. AI를 다루는 기본기.
- **2탄 「AI 창작 공방」** — 매 차시 완성품 1개: 장르 변신 이야기, 나만의 캐릭터, 학급 광고 문구, 검증 완료 퀴즈.
- **3탄 「AI 프로젝트 스튜디오」** — 모둠(4인)이 4차시 관통 프로젝트 1개를 기획 → 제작 → 다듬기 → 쇼케이스로 완성 (학급 잡지·캠페인·텍스트 게임 등 메뉴 5종).

지도안·학생 학습지·교사 키트(체크리스트, 트러블슈팅, 프롬프트(AI에게 건네는 질문·부탁의 말) 스니펫, 평가 루브릭 등)·확장 자료까지, 교사가 이 저장소 하나로 준비부터 평가까지 마칠 수 있도록 구성했습니다. 로그인이 없으므로 계정 발급·보호자 동의서 수합 없이 시작할 수 있고, 접속 실패·기기 부족에 대비한 플랜 B가 모든 차시에 들어 있습니다.

## 📖 웹 교재로 보기 (배포·열람용)

이 패키지 전체를 담은 **오프라인 웹 교재**가 `web/` 폴더에 들어 있습니다. 서버·설치·인터넷 없이 **`web/index.html`을 브라우저로 열기만 하면**(더블클릭) 동작하며, 배포 시 `web/` 폴더 하나만 전달해도 됩니다.

- **수록 기능**: 전체 문서 20종 열람, 전문 검색(단축키 `/`), 실습 프롬프트 복사 버튼, 사전준비 체크리스트 체크 상태 저장, **차시별 20분 수업 타이머**(단계 자동 안내·전환 알림음), 학습지·포스터·안내문 인쇄 모드(브라우저 인쇄 → A4), 밝은/어두운 화면, 글자 크기 조절, 모바일·태블릿 대응.
- **수정 방법**: 원본은 어디까지나 이 저장소의 마크다운 문서입니다. 마크다운을 고친 뒤 `cd tools && npm install`(최초 1회) 후 `node tools/build-web.js`를 실행하면 웹 교재에 반영됩니다.

## 시리즈 아크 요약 (3탄 × 4차시 = 12회차)

### 1탄 「AI 리터러시 기초」

| 차시 | 제목 | 핵심 질문 | 산출물 |
|---|---|---|---|
| 1 | AI와 첫 만남 — 인공지능은 어떻게 말할까? | AI는 어떻게 말을 만들까? | 첫 대화 기록 |
| 2 | 프롬프트의 기술 — AI에게 잘 부탁하는 법 | 어떻게 부탁해야 잘 나올까? | 나만의 레시피 카드 |
| 3 | AI 거짓말 탐정 — 환각 수사대 | AI의 말은 다 사실일까? | 수사 보고서 |
| 4 | AI와 함께 살아가기 — 정직한 사용 선언 | AI를 어디까지 써도 될까? | 나만의 AI 사용 선언문 |

아크는 "확률로 말을 만든다 → 잘 부탁하면 잘 나온다 → 그럴듯한 거짓도 만든다 → 어떻게 쓸지는 내가 정한다"의 순서로 쌓입니다.

### 2탄 「AI 창작 공방 — 말로 만드는 것들」

| 차시 | 제목 | 산출물 | 핵심 기술 |
|---|---|---|---|
| 1 | 이야기 공장 — 장르 변신 스토리 | 나만의 미니 이야기 | 재료 조립 프롬프트 + 장르 변신 멀티턴 |
| 2 | 캐릭터 공방 — 나만의 캐릭터 설계 | 캐릭터 프로필 카드 | 설정 설계 + 캐릭터 인터뷰 |
| 3 | 학급 광고 기획사 — 마음을 움직이는 문구 | 캠페인 문구 세트 | 타깃·톤 지정 A/B 실험 |
| 4 | 퀴즈쇼 제작단 — 내가 만드는 문제 | 검증 완료 퀴즈 3문항 | 생성 + 검증 3단계(출제자의 책임) |

2탄부터는 **창작 3원칙**이 관통합니다: ① 정하는 건 나 ② AI는 재료 공장 ③ 고쳐 써야 내 작품.

### 3탄 「AI 프로젝트 스튜디오 — 팀으로 완성하는 작품」

| 차시 | 제목 | 산출물 |
|---|---|---|
| 1 | 기획 회의 — 무엇을 만들까? | 한 장 기획서 |
| 2 | 제작 스프린트 — 초안 공장 | 파트별 초안 모음(팀 기록지) |
| 3 | 다듬기 공방 — 내 문장으로, 사실 확인까지 | 프로젝트 완성본 |
| 4 | 쇼케이스 — 발표와 회고 | 팀 발표 + 회고 카드 |

모둠 4인(기획 리더 / 프롬프트 담당 / 기록 담당 / 검증 담당)이 프로젝트 메뉴 5종(학급 잡지 · 공익 캠페인 · 텍스트 어드벤처 게임 · 우리 반 사용 설명서 · 노래 가사+콘티) 중 하나를 골라 완성합니다. 기기는 모둠당 1~2대면 충분합니다.

모든 차시는 합계 정확히 20분이며, 게스트 모드(텍스트 전용·기록 미저장) 전제와 안전 수칙(개인정보 금지·검증·정직한 표시)을 공유합니다.

## 주의 문구 (사용 전 반드시 확인)

- **기준일**: 이 패키지의 정책·기능·연령 관련 서술은 **2026년 7월 조사 시점 기준**입니다. AI 서비스는 예고 없이 바뀌므로 **실제 접속 화면이 최종 기준**입니다. 수업 전 게스트 접속 테스트를 생략하지 마십시오.
- **게스트 모드 전제**: 본편 4개 차시는 로그인 없이 진행합니다. 게스트 모드에서는 **이미지 생성·파일 업로드·대화 기록 저장이 불가능**하며, 학생에게 개인 구글 계정 로그인을 지시하지 않습니다(한국 자체 관리 연령 만 14세, 개인정보 보호법 제22조의2 관련 — 근거는 `appendix/제미나이-조사-정리.md`).
- **법률 자문 아님**: 이 패키지는 수업 설계 참고 자료입니다. 개인정보·계정 정책에 관한 최종 판단은 공식 문서, 학교 규정, 학교 개인정보 담당자·관리자와의 협의를 따르십시오.
- **AI 답변 예시**: 문서에 실린 AI 답변은 모두 "예시 답변(실제 결과는 매번 다름)"입니다. 같은 프롬프트라도 결과는 매번 달라지며, 수업은 어떤 결과가 나와도 성립하도록 설계되어 있습니다.
