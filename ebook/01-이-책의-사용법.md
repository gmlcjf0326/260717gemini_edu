# 이 책의 사용법

이 책은 처음부터 순서대로 읽어도 되고, 필요한 페이지만 뽑아 써도 되는 **실전 교재**입니다. 상황별 읽기 경로와 책의 규칙을 안내합니다.

## 1. 책의 구성

| 부 | 내용 | 이런 분께 |
|---|---|---|
| 제1부 수업을 열기 전에 | 교육과정 개요, 준비 체크리스트, 트러블슈팅, 학부모 안내문, 안전수칙 포스터 | 수업을 계획·준비하는 모든 분 |
| 제2부 1탄 · AI 리터러시 기초 | 4개 차시 지도안+학습지, 프롬프트 대본집, 평가 루브릭 | 첫 수업을 시작하는 분 |
| 제3부 2탄 · AI 창작 공방 | 매 차시 완성품을 만드는 4개 차시 + 대본집·루브릭 | 만들기 수업으로 확장하는 분 |
| 제4부 3탄 · AI 프로젝트 스튜디오 | 팀 프로젝트 4개 차시 + 메뉴별 프롬프트·2축 평가 | 협업 프로젝트까지 가는 분 |
| 제5부 수업을 더 풍성하게 | 돌발질문 FAQ, 작품 전시 키트, 확장팩(이미지 차시)·동아리 | 운영 중 참고 자료가 필요한 분 |
| 부록 | 제미나이 정책·법령 리서치 원문, 저장소 안내, 출판 가이드 | 근거를 확인하고 싶은 분 |

각 차시는 **지도안(교사용)과 학습지(학생 배부용)** 한 쌍으로 구성됩니다. 지도안에는 분 단위 흐름표·발문 스크립트·오개념 대응·시간 조정 가이드·플랜 B가 12개 섹션으로 들어 있고, 학습지는 A4 1~2장으로 인쇄해 바로 나눠 줄 수 있습니다.

## 2. 상황별 읽기 경로

**"수업이 내일입니다"** — 최단 경로 네 페이지만 읽으십시오.
1. 사전준비 체크리스트(제1부)의 D-1 항목 실행 — 특히 학교 네트워크에서 시크릿 창으로 **게스트 접속 3회 테스트**
2. 1탄 1차시 지도안(제2부) 정독 — 20분 수업엔 애드리브 여유가 없습니다
3. 프롬프트 스니펫(제2부)에서 1차시 프롬프트를 교사 기기로 1회 사전 실행
4. 1차시 학습지 인쇄 — 게스트 모드는 기록이 저장되지 않으므로 **학습지가 곧 저장소**입니다

**"시리즈 전체를 설계합니다"** — 제1부 교육과정 개요 → 각 부의 개요 페이지(2탄 개요·3탄 개요) → 학부모 안내문 발송 순서로 보시면 전체 그림이 잡힙니다.

**"평가와 기록이 고민입니다"** — 각 부 끝의 평가 루브릭(1·2·3탄)을 보십시오. 관찰 기호와 별명 체계는 세 문서가 공유하며, 생기부 기록 예시문이 각 5개씩 들어 있습니다.

**"학생이 이상한 질문을 합니다"** — 제5부 돌발질문 FAQ에 23개 질문의 20초 답변이 있습니다.

## 3. 이 책의 규칙 (모든 페이지가 공유하는 전제)

- **게스트 모드 전제**: 본편 12차시는 gemini.google.com의 "로그인 없이 사용"만 씁니다. 이미지 생성·파일 업로드·대화 기록 저장이 되지 않으며, 그래서 "마음에 드는 결과는 즉시 옮겨 적기"가 모든 실습의 기본 동작입니다. 이미지 생성은 학교 Workspace 계정이 확보된 경우의 확장팩(제5부)에서만 다룹니다.
- **개인정보 금지**: 이름·생일·주소·연락처·학교/반/번호·가족·사진·계정을 AI에 입력하지 않습니다. 학습지에도 실명 대신 **별명**을 씁니다(별명-실명 대응은 교사 명렬표로 관리).
- **용어 통일**: 프롬프트 레시피 4요소(역할–상황–요청–형식) / 검증 3단계(의심하기·비교하기·물어보기) / 창작 3원칙(정하는 건 나 · AI는 재료 공장 · 고쳐 써야 내 작품) / 정직한 표시("AI와 함께 만들었어요"). 이 네 가지가 시리즈 전체의 뼈대 언어입니다.
- **예시 답변 주의**: 책에 실린 AI 답변은 모두 예시이며, 확률 생성의 특성상 실제 결과는 매번 다릅니다.

## 4. 웹 교재(전자책 뷰어) 활용

이 책의 웹 버전은 브라우저에서 열기만 하면 동작하며(설치·인터넷 불필요), 종이책에는 없는 기능이 있습니다.

- **검색**: 단축키 `/` — 전체 페이지에서 낱말을 찾아 해당 위치로 이동합니다.
- **수업 타이머**: 상단 ⏱ 버튼 — 차시를 고르면 그 차시의 실제 흐름표 단계("실습② 미션1" 등)를 20분 동안 자동 안내합니다. 지도안 페이지에서 바로 열 수도 있습니다.
- **인쇄**: 학습지·포스터·안내문 페이지의 🖨 버튼 — 화면 요소를 걷어낸 A4 인쇄 레이아웃으로 출력됩니다.
- **프롬프트 복사**: 실습 프롬프트 상자에 마우스를 올리면 복사 버튼이 나타납니다. 수업 중 화면 게시용으로 쓰십시오.
- **읽음 표시**: 한 번 연 페이지는 목차에 ✓ 로 표시되고, 표지에서 "이어서 읽기"로 마지막 페이지로 돌아갈 수 있습니다.

학생·가정 배부용으로 설계된 페이지는 다음과 같습니다: 각 차시 **학습지 12종**, **안전수칙 포스터**, **학부모 안내문**, **작품 전시 키트**(명패·관람 활동지). 나머지는 교사용 화면 열람을 전제로 합니다.
