## 오늘의 미션

오늘부터 4번의 수업 동안 우리 팀은 **작품 하나**를 끝까지 완성해요(기획 → 제작 → 다듬기 → 쇼케이스). 오늘은 그 첫걸음, **기획 회의**! ① 역할을 나누고 ② 메뉴에서 주제를 고르고 ③ AI에게 아이디어 재료를 받아 ④ **한 장 기획서**를 완성해요. 기억해요 — AI가 아이디어를 줘도, **정하는 건 우리 팀**!

## 1번. 팀 세팅 — 역할을 나눠요

역할 옆에 맡은 사람의 **별명**을 써요. (역할은 다음 시간에 바꿔 맡을 수 있어요!)

| 역할 | 하는 일 | 별명 |
|---|---|---|
| 기획 리더 | 회의 진행, 시간 관리, 의견이 갈리면 결정 이끌기 | |
| 프롬프트 담당 | 팀이 함께 만든 프롬프트를 기기에 입력하기 | |
| 기록 담당 | AI의 답 중 쓸 만한 것을 **그 즉시** 이 종이에 옮겨 적기 | |
| 검증 담당 | 개인정보·실제 인물이 들어가지 않는지 점검하기 | |

## 2번. 프로젝트 메뉴 — 토의하고 투표해요

우리 팀이 고른 메뉴에 **동그라미**! (자세한 소개는 선생님이 나눠 준 메뉴 카드를 보세요. 동점이면 기획 리더가 결정!)

| 고르기 | 메뉴 | 만드는 것 |
|---|---|---|
| ( ) | A. 학급 잡지 한 페이지 | 기사 2꼭지 + 광고 1 |
| ( ) | B. 공익 캠페인 패키지 | 슬로건 + 포스터 문구 + 30초 안내 방송 대본 |
| ( ) | C. 텍스트 어드벤처 미니 게임 | 도입 + 선택지 2갈래 + 결말 2개 |
| ( ) | D. 우리 반 사용 설명서 | 신입생·전학생 안내 5항목 |
| ( ) | E. 노래 가사 1절 + 뮤직비디오 콘티 | 가사 1절 + 글 5장면 |

⚠️ 어떤 메뉴를 골라도 실제 친구·선생님·연예인은 작품에 등장시키지 않아요. 인터뷰 기사도 "익명·별명 인용"으로!

## 3번. AI 브레인스토밍 — 「아이디어 5개 뽑기」

프롬프트 담당이 아래 문장에서 **[메뉴] 자리에 우리 팀 메뉴 이름만 바꿔 넣어** 입력해요.

> 입력할 프롬프트: **우리 팀은 [메뉴]를 만들 거야. 중학생 눈높이의 아이디어 5개를 제목만 써 줘**

**먼저 기록, 그다음 투표!** 기록 담당은 AI가 준 아이디어 5개 제목을 지금 바로 옮겨 적어요. 다 적은 뒤 팀 투표로 1개를 골라 ⭐ 표시! (다 별로면 우리 팀 아이디어를 6번에 쓰고 그걸 골라도 돼요 — 정하는 건 우리 팀!)
