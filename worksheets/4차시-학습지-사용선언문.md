## 3번. AI에게 규칙 초안 부탁하기

**① 입력할 프롬프트**(AI에게 건네는 질문·부탁의 말) — 새 대화(＋)를 열고 아래 문장을 그대로 입력해요.

> **중학생을 위한 AI 사용 규칙 5가지 초안을 짧은 문장으로 써 줘**

**② AI가 준 초안 중에서 '나에게 꼭 필요한 것' 2개를 골라, 지금 바로 그대로 옮겨 적어요.**
(게스트 모드는 창을 닫으면 대화가 전부 사라져요. 미루면 사라져요!)

고른 초안 1: _________________________________________________

고른 초안 2: _________________________________________________

## 4번. 나의 AI 사용 선언문 완성하기

3번에서 옮겨 적은 초안 2개를 **내 문장으로 고쳐서** 제1조·제2조에 쓰고, 제3조는 AI가 말하지 않은 **나만의 규칙**을 발명해서 써요.

고쳐 쓰기 조건 세 가지! ✔ 내 생활 단어 넣기(숙제·수행평가·단톡방·게임…) ✔ "나는 ~하겠습니다 / ~하지 않겠습니다" 다짐 문장으로 ✔ AI 문장 글자 그대로 베끼지 않기

```
┌────────────── 나의 AI 사용 선언문 ──────────────┐
│                                                  │
│  나 ____________(별명)은 AI를 똑똑하고 정직하게  │
│  사용하기 위해 다음과 같이 선언합니다.           │
│                                                  │
│  제1조 (AI 초안 → 내 문장으로)                   │
│  나는 _________________________________________  │
│  ______________________________________________  │
│                                                  │
│  제2조 (AI 초안 → 내 문장으로)                   │
│  나는 _________________________________________  │
│  ______________________________________________  │
│                                                  │
│  제3조 (내가 발명한 나만의 규칙)                 │
│  나는 _________________________________________  │
│  ______________________________________________  │
│                                                  │
│  ☐ 정직한 표시: 이 선언문은 AI(제미나이)의       │
│     초안을 참고해서 내가 직접 고쳐 썼어요.       │
│                                                  │
│  선언한 날: ____월 ____일   서명(별명): ________ │
│                                                  │
└──────────────────────────────────────────────────┘
```

다 쓰고 나서 아래 체크! (하나라도 빠졌으면 아직 미완성이에요.)

☐ 제1·2조에 내 생활 단어가 들어 있어요  ☐ 세 조항 모두 다짐 문장이에요  ☐ 제3조는 AI 초안에 없던 내 아이디어예요  ☐ 정직한 표시에 체크하고 서명했어요
